<h1>Project: Recipes</h1>

A static site that has links for several recipes.<br>
This project is based on <a href="https://www.theodinproject.com/" target="_blank" rel="noreferrer">The Odin Project</a>.

<h3>Features</h3>

- Each recipes are stored in separate pages.

- Recipe data is from <a href="https://www.allrecipes.com/">allrecipes</a>.

- Homepage photo is from <a href="https://unsplash.com/">Unsplash</a>.

- Responsive Design implemented.

<h3>Tech Stack</h3>

- Frontend: HTML CSS
